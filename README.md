# Breakout

A classic arcade game recreated with Unity and C#.

## Gameplay

![Breakout Gameplay](BreakoutGif.gif)

Control the paddle, bounce the ball, and destroy all the bricks without losing all your lives.

## Features

* Procedurally generated brick layout.
* Paddle and ball physics.
* Score and lives system.
* Win and game over screens.

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/JpMunhozOliveira/Breakout-Unity-Csharp.git
   ```

2. Open the `Breakout` folder in Unity Hub.

3. Open the project with Unity `2021.3.16f1`.

4. Open the game scene and press **Play**.
